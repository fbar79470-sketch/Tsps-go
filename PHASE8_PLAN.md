## 2. Integration contracts

- Session holds `musicData` (nil = TS empty-areas/no-lengths
  behavior); wiring sets it at AddPlayer time.
- Ground-item sends cross the game/session boundary through a
  `GroundItemSender` interface implemented by the cmd/server
  adapter (type-asserting `p.Session`, the `appearanceBlock`
  pattern) — the game layer never imports protocol and the
  session layer never imports game.
- FlushTick region-change reads visible items through a
  per-session source closure installed by the adapter.
- Audio settings stay PRESERVED in the save merge (nothing in
  Go mutates them); the Player only snapshots them at entry.
